## 学习方式

每次研究一个具体行为：阅读对应源码，形成自己的解释或预测，运行或调试验证，再修正理解。

代码旁记录局部理解和疑问，本文档目录记录完整调用链和实验过程。未核实的判断注明“待验证”；实验记录参考提交、配置、操作、实际结果与剩余问题。
