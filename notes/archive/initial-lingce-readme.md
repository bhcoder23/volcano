# 灵策 · Lingce

**灵于调度，策排任务。**

灵策是一个以 Volcano 及其前身 kube-batch 为参考、从零手写的云原生批计算调度学习项目。面向云上大数据与 AI 训练基础设施，从可运行的最小调度闭环开始，逐步学习并实现作业管理、调度策略、资源治理和生产工程能力，再思考自主设计。

## 当前阶段

项目说明与 MVP 迭代路线已建立，业务代码尚未开始。当前进行静态分析和规划；后续由学习者手写，每个里程碑运行验证后再继续迭代。详见 [学习与 MVP 路线](docs/ROADMAP.md)。

## 学习目标

从 Go 与 Kubernetes 基础出发，逐步具备设计、部署、运维和扩展基于 Volcano 的批计算调度平台的能力。

学习范围覆盖 API、Admission、Controller、作业生命周期、调度缓存、调度框架与策略、设备与拓扑、节点资源治理、工作负载集成，以及测试、性能、可观测性、高可用和发布升级。

最终通过真实工作负载接入、资源竞争、故障恢复、性能验证和升级回滚等实践，建立生产使用依据。

## 实现原则

- 项目、模块与组件使用 Lingce 的身份；API Group、标签、注解等对外标识统一设计，不能通过全局替换上游名称来确定。
- 学习上游的概念和实现。Job、TaskSpec、PodGroup、Queue 等通用名称保持对应；包、结构体和字段随实际功能逐步引入，并记录与参考源码的关系。
- 从最小可运行闭环出发，每次围绕一个明确行为增加代码和必要抽象。
- 每个学习单元先解释场景和前置知识，再追踪源码，由学习者手写业务实现并进行代码审查。
- 为学习暂时省略的字段、分支和机制应明确记录，随后逐步补齐。
- 从第一版纳入正确性必需的错误处理、资源核算和幂等约束，随后逐步补齐健壮性、性能与生产能力。
- 逐项记录实现范围及验证结果；源码参考关系和 API 兼容是不同目标，与 Volcano 的兼容性需要单独验证。
- 完整理解和实践之后，再讨论自主架构和功能演进。
